# Refuerzo de páginas prioritarias — 16 sep 2026

Objetivo: mejorar claridad, utilidad y señales de actualización de páginas ya existentes sin añadir URLs.

## Cambios

- Portada: se retiró de destacados la previa del encuentro del 16 de septiembre, ya pasado, y se enlazó el siguiente Clásico Nacional. Se añadió acceso directo a la guía del VAR.
- Guías de arbitraje, VAR, Liga Femenil, descenso y campeones: se añadieron explicaciones prácticas, distinciones entre temporadas y enlaces a fuentes primarias cuando están disponibles.
- Páginas “cuándo juega” de América y Cruz Azul: se aclaró el alcance, se enlazó la fuente de horarios y se retiró de próximos partidos el encuentro ya disputado de Cruz Azul con Inter Miami. La lista estructurada de Cruz Azul quedó con tres partidos futuros.
- Horarios del 19 de septiembre contrastados con las designaciones de la Comisión de Árbitros FMF: América–Guadalajara 21:15 y Monterrey–Cruz Azul 19:10, hora del centro de México. Se corrigieron fichas, calendario, Jornada 9, páginas de equipos y datos de demostración para mantener consistencia.
- Sitemap: se actualizaron las fechas `lastmod` sólo en las páginas cuyo contenido cambió. No se agregaron ni quitaron URLs.

1. **Site Audit:** errores de rastreo, enlaces rotos, profundidad de clic y páginas internas débiles.
2. **On Page SEO Checker:** sugerencias para emparejar una keyword principal con cada URL existente y detectar oportunidades de contenido, sin abrir una URL por variación.
3. **Keyword Magic Tool (México):** ampliar preguntas y subtemas dentro de las páginas actuales usando volumen, KD e intención.
4. **Position Tracking:** comenzar a medir las keywords prioritarias cuando Google indexe las primeras páginas; la herramienta no sustituye el estado de Search Console.
